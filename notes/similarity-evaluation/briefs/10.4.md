## What to build

### The module `pangloss_reconcile` (in `packages/pangloss-reconcile/src/pangloss_reconcile/interface/`)

- `slots: { reconcileCandidates: { Candidates: () => import("./components/ReconcileCandidates") } }`, nothing
  else. The props' shape is said in the module itself (a module cannot import review's file): `{ mention: { id:
  string; label: string; unreconciledType: string }, onPick(found: { type; id; label? }) }`, taking of the mention
  only what it reads.
- `api.ts`: `getCandidates(api, id)` → the answer's type. `candidates.ts`: pure helpers with their tests (which
  rows to show, the figure's text, the bar's width, the text of a part's score), as `similar.ts` is.
- `ReconcileCandidates.tsx`, drawn by review above its picker:
  - a small heading in the panel's own style of heading ("Reconcile with" there is `text-xs font-semibold
    text-slate-500 uppercase`): "Suggested";
  - each candidate a row: its `ReferenceChip` (a link to its page, as chips are), a slate bar and figure for
    the score exactly as the Similar section's row has them (reuse by the same classes; do not import the other
    module's file), and **a button that chooses it** ("Choose", `buttonClass("quiet", "sm")` or what the panel's
    own "Change" button uses): the chip stays a link, the button calls `onPick` with the candidate's type, id
    and label. Under the row, quietly, the reasons: "also named with" and the `shared` entities as
    `ReferenceChip`s (small, if the chip has a small size), each with its count only when above 1; nothing
    under a candidate that shares nothing. The parts' scores as the bar's `title`/accessible text ("name 0.95,
    graph 0.41"), not as more columns;
  - at most 5 rows (ask the route for `limit=5`);
  - nothing at all (no heading) when: the answer has no candidate; the status is `pending`; the request fails
    (review's slot already hides a failure: let it throw). With `rebuild_due` show the candidates.
  - It reads by itself (a memo of the request keyed by the mention's id and the session, as `SimilarSection`
    reads): another mention, another request.
- Translations for every text, three languages. The Python package's manifest/packaging for an interface module
  as `pangloss-vectors` has it; `pangloss interface check` passes on the e2e project.
