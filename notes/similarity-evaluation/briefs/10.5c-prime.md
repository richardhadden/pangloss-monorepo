## Why

The user's own pipeline today takes the suggestions by name, looks more up about each, and asks a language
model. A project should be able to put that judgement **inside** the worker: Pangloss finds the candidates and
makes its own decision; the project's function may replace it. The function is the project's code: what it
sends elsewhere is the project's to decide (said in the guide).

## What to build

1. **The setting** `RECONCILE_SUGGEST_WITH` (None): `"package.module:function"`; checked at `initialise()` when
   set: the form, importable, callable (the import's own error in the message). `RECONCILE_SUGGEST_TIMEOUT`
   (60; seconds, a number above 0).
2. **What the judge is given**: one argument, a frozen dataclass `Asked` of **plain data** (dicts, lists,
   strings, numbers: nothing of the database, nothing it could write through), exported from the package root
   with the answer's classes so that a project can type its function:
   - `stand_in`: its id, label, the class it stands for (`stood_for`), its URIs, and where it sits (the names of
     the fields from the head down to it, and the type of the node that holds it);
   - `document`: the head as it was read, as JSON-ready data (`view.model_dump(mode="json", by_alias=False)`
     or as the API would give it: choose, say which, and keep it stable);
   - `candidates`: as the dialog would be answered (`candidates.DISPLAYED` of them): each with its reference
     (id, type, label), `score`, `scores` by part, and `shared` (the entities it is named with, as the route
     answers them);
   - `decision`: what 10.5c decided: the alternatives (id, type, percent) and the reason;
   - `takes`: the shape the place takes (`"alternatives"` or `"one"`) and the names of the classes of entity it
     takes (so that a judge knows what it may name).
3. **What it answers** (sync or async; a sync function is run in a thread so that the lease's renewal goes on):
   - `None`, or `Unchanged()`: the decision stands;
   - `Leave()`: nothing is suggested for this mention (noted as tried, as a decision of nothing is);
   - `Suggest(alternatives=[(reference, weight), ...], fields={...})`: **its own alternatives**: entities by
     `{"type", "id"}` with weights above 0, **which need not be among the candidates**; the worker makes whole
     per cent of the weights (`suggest.percentages`), cuts nothing (but where the place takes one entity, the
     heaviest only), and writes them as it writes its own. `fields`: values for further fields of the
     suggestion's class (`RECONCILE_SUGGEST_AS` may name a project's subclass with, say, a `note`), never the
     fields the worker fills (`type`, `id`, `text`, `uris`, `identified_by`, `toolchain_version`, `target`:
     naming one is a bad answer).
   - **A bad answer** (another type; no alternative; a weight that is not a number above 0; a reference without
     type and id; more than 100; a worker's field in `fields`) is a failure of the judge (below), with a message
     that says what was wrong. What only the write can find (an entity that does not exist or that the place
     does not take, an unknown field of the class) is found **by the trial before the write**
     (`prepare_rewrite` with that one replacement, and the entities looked up as the write would: find the
     cheapest check that an entity exists and is not deleted or merged away) and is also a failure of the judge
     **for that mention only**.
4. **A failure or a timeout** (the user confirmed main's calls): the mention is **left as it is, logged with
   the head and the stand-in, and not noted as tried** (the next trigger asks again); **the built-in decision
   is not used in its place**; and it **never fails the rest of the document**: the other mentions of the head
   are still written in the one update. The head's mark: completed as for any head done (the mention is asked
   again by the next save or trigger, since it is not "tried"); say if the code makes another rule more
   natural. A judge that is cancelled by the timeout must not leave the worker's lease or claims unrenewed
   (the renewal runs beside it: test with a slow judge).
5. **`toolchain_version`** says that a judge was used (`"profile who, judge package.module:function"`, with the
   fit as now), for every suggestion of a batch in which one was configured, changed by it or not.
6. **Learning** (10.5f's rules stand): the rows kept for a suggestion are **the worker's own candidates with
   their numbers**, `displayed` **what was written** (so an entity the judge added that a person confirms is
   "none of those offered" to the fit, rightly). What a judge suggests is no more evidence than the worker's
   own (10.5c: nothing to build, a test). With no setting **nothing is called and the cost is the same** (the
   judge's data is not even built).
7. **Docs**: `implementation_docs/reconcile.md` (the judge, its data, its answers, its failures);
   `guide/vectors/reconcile.md`: **a worked judge** that looks each candidate up (through the models, from
   inside the function: say plainly that this runs in the worker's process, as the worker's user, and that
   what it sends to a model's API is the project's own decision and responsibility) and asks a language model,
   as a sketch with the model call left as a function of the project's (`ask_model(prompt) -> str`): no
   provider's SDK in the guide; `status.md`; the skill's row (+ `check_skill.py`). Not
   `similarity-build-plan.md`, not `TODO.md`.

## Tests

- **Pure** (`packages/pangloss-reconcile/tests/`, a new file): the setting's refusals by message; each answer's
  shape checked with its message (weights, a missing type or id, a worker's field, another type, none, too
  many); weights to per cent; the one-entity shape takes the heaviest; `toolchain_version`.
- **Live, both backends** (`tests/live/`, a new file; judges are functions of the test module named in the
  setting): unchanged (`None` and `Unchanged()`); `Leave()` (the mention stays, noted as tried); replaced by
  its own alternatives among the candidates; **an entity added that is not among the candidates** (written;
  the kept rows are the worker's candidates and `displayed` what was written); extra `fields` on a subclass
  named by `RECONCILE_SUGGEST_AS`; an entity the place does not take, one that does not exist, an unknown
  field: that mention left, **not tried**, the other mention of the same document written; a judge that
  raises; a judge that times out (a timeout of 0.2 s in the test); **a slow judge with the lease and the claims
  kept** (a second worker does not take the head meanwhile); a sync judge; with no setting nothing is called
  (a judge module that would raise on import is never imported) and the write's statements are the same; a
  judge's suggestion changes no later score (as 10.5c's live test, once).
- Then `ruff format --check packages`, `ruff check --select F,B packages`, `ty check`.
