## 8.5 Tables of variants

> `NAMES_VARIANTS`: a file in the project (CSV: a canonical form and its variants), read at `initialise()`,
> refused by line when wrong. Its hash is in the signature, so a changed table makes a rebuild due for this part
> alone.

- The setting `NAMES_VARIANTS`: a path (absolute, or relative to the project's directory: find how another setting
  that names a file is resolved, or resolve against the settings module's directory, and say which), or None.
- The file: CSV, UTF-8, one line for each canonical form: the form first, then its variants
  (`Johannes,Johann,Hans,Jan`). Blank lines and lines starting with `#` are skipped. Each cell is one word after
  folding (`maths.fold`).
- `pangloss_names.settings.variants() -> dict[str, str]` (already called by the part; it gives `{}` today): the
  table of `maths.variants_table`, read once and remembered for the settings object, forgotten when the registry
  is reset. `variants_hash()` for the signature: a hash of the table's content (not of the file's bytes: a comment
  added changes nothing).
- Checked at `initialise()` when the app is installed (as `pangloss_vectors.check_profiles` hooks
  `ModelRegistry.after_finalise`): a file that is not there, a line with no variant, a cell of two words, a variant
  of two canonical forms, a variant that is a canonical form: each refused with `PanglossInitialisationError`
  naming **the file and the line**. (`maths.variants_table` raises `ValueError` without a line: check line by line
  here, or wrap; do not change `maths.py` unless it cannot be done otherwise, and then say so.)
- *Pure* (`tests/test_names_variants.py`): variants found; each refusal, by its line; a changed file changes this
  part's signature and no other's (the class part's and the graph part's are the same before and after); a comment
  added changes nothing; no setting gives `{}`.
- *Live* (in `tests/live/test_names_part_live.py` or a file beside it): with a table, a person stored as
  `Hans Mayer` and a search from `Johannes Mayer`'s vector are at cosine 1; after the table changes, the part's
  status says a rebuild is due (see how `status` says it for a changed signature) and the other parts' do not.
- **A typology as a table is not in this step** (the plan says why).

## 8.6 By a name

> `pangloss_names.vector_of(text)` and `pangloss names search "Jon Smyth" --type Person` (through
> `nearest(vector=…)`; `guide/cli.md`). No route yet: phase 10's is the one a client asks.

- `async pangloss_names.vector_of(text: str | Iterable[str]) -> list[float] | None`: the name vector of a text (or
  of several names of one item) by the table of rarity **in use** (`store.kept`, through the part's remembered
  table) and the table of variants; None if the text has no letters or digits. Raises a clear error if the part
  has never been built ("run `pangloss vectors rebuild`").
- `async pangloss_names.search(text, *, types=None, profile=None, k=10, see_unpublished=False) -> Nearest`:
  `nearest(vector={"name": vector}, ...)`. The profile: the one named, or else the first profile of the settings
  that weighs `name` (in the order of their names); if none does, a clear error saying that a profile must weigh
  the name part (`VECTORS_PROFILES = {"who": {"name": 1, "graph": 0.25}}`). A search from a name has only the name
  part in its query: read `store.Layout.combine` and `search.nearest` for what a query with one part gives against
  stored vectors of several, and say in the report what the score then means (it is not the cosine of the names).
- The command `pangloss names search TEXT [--type NAME ...] [--profile NAME] [-k 10]` in `pangloss_names/cli.py`
  (as `pangloss_vectors/cli.py` is registered): a line for each hit, score, type, label, id. Unpublished documents
  are shown (the command line is the project's owner, as `pangloss vectors` commands are: check and follow).
  `guide/cli.md` gets the command (its test fails otherwise).
- *Live* (`tests/live/test_names_search_live.py`, both backends): a spelling variant and a namesake are found,
  ranked (the same name first, the variant spelling next, another name not among them or last); narrowed by type;
  **an unpublished item is not shown to a reader who is not logged in** (`declare(reviewed=True)`, a document class
  with names: make one in the test's models or give `Factoid` names by a class of the test; see how the search
  tests of `pangloss-vectors` do it) and is with `see_unpublished=True`; **a merged entity is not a hit and its
  survivor is**; the command prints the hits (as `test_vectors_commands_live.py` runs a command).
