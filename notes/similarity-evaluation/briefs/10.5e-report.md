# 10.5e report (builder): what sets the worker off, choices as they were made

Written as the work goes; the summary is at the end.

## Found before building

- `guide/cli.md` did not list `pangloss reconcile worker` (10.5d's command): `test_cli_guide.py` failed on it before
  this step (`1 failed` with `-k reconcile`). Its row is added here with the new commands.
- The vectors' rebuild wakes no worker (nothing in `rebuild.py`, `api.py`, `cli.py` calls a wake): the trigger
  uses the general hook, `hooks.emit_work_marked(model)`, once for each class it marked, after the marks are
  committed. 10.5d's `marking.marked` already listens to it and wakes this process's worker for a class it can mark.
  (The vectors' and derived's listeners hear it too, and look for work of theirs: none is there, so they find
  nothing.)

## Choices

1. **The query of a page** (`suggesting.STORED_PAGE_QUERY`, `STORED_HEADS_QUERY`): the stand-ins found by the label
   of each stand-in class (`MATCH (s:Unreconciled)`: every document class has an index of its label), their heads as
   `coalesce(s.head_node_id, s.id)` (the head itself may be the stand-in), after the last head of the page before,
   grouped, ordered and cut to the page; then those heads by `HeadNode(id)`, kept when of a class to mark, not
   deleted, unpublished. Both in one read transaction; the marks (and what is forgotten) in one write transaction.
   Each page reads the label's stand-ins after the cursor again (no index of `(Unreconciled, head_node_id)` exists,
   and adding one is a migration of review's): the cost of a run grows with the stand-ins × pages, not with the
   nodes of the database. Not measured (the brief: measure nothing). Planned by no one at size: **main should
   EXPLAIN it on `:7690`/Neo4j before relying on it.**
2. **Several stand-in classes**: one statement for each label, less a label whose class is below another of them
   (`stand_in_labels`); the page ends at the smallest last head of a label whose page is full, so that no head
   between is passed over. With review alone, one label, one statement.
3. **Row 23 in the core**: `pangloss_cypher.pending.mark_unmarked(tx, kind, heads)` (`OPTIONAL MATCH` the old mark,
   then `MERGE ... ON CREATE SET`): a head that has a mark keeps its token and its claim; gives the heads it marked.
   In `pending.py` with the key format and the label, as 10.5d's `claim(before=)` and `renew` were. A write that
   marks the same head at the same moment meets the unique constraint on `key` and is run again by the driver.
4. **`again` forgets by stand-in, not by head**: `forget_tried(heads)` finds `PGReconcileTried` by `head`, which has
   no index (a scan of the label for every page). The trigger deletes them by the ids of the stand-ins it found
   (`PGReconcileTried(stand_in)` is indexed), in the page's write before the marks: the same rows for every stand-in
   the head holds now (a row of a stand-in no longer there is of no use, and the sweep takes it). `forget_tried` is
   unchanged.
5. **`again` forgets for every head found, marked now or already** (a head already waiting is asked again too).
6. **What `Marked` counts**: `marked`, `already`, `stand_ins` (of the heads found, marked now or already), and
   `forgotten` (the rows of `again`; 0 without it). The API answers them camelCase (`standIns`).
7. **The classes**: `classes_to_mark(classes)`: every class that can be marked (10.5d's `suggestible_classes`), or
   those that are a class named or below one. A name is refused (`NotSuggestible`, a `ValueError`) when it is no
   model or no class that can be marked is it or below it; the message names the classes that can. The route answers
   it 422, the command `Refused: ...` and exit code 1.
8. **Waking**: after the last page, `hooks.emit_work_marked(model)` for each class of which a head was marked now
   (none when nothing was marked).
9. **The admin job `reconcile_suggest`**: jobs take options (`Flag`, `Choice`): `again` is a `Flag`. The classes are
   **not** an option: a job's options are declared when `admin.py` is imported, which may be before the models are
   (the vectors' job imports the apps for its parts; the classes that can be marked are known only after
   `initialise()`), so the job marks every class. Its counts `marked`, `already`, `stand_ins`, `forgotten`; their
   words, the title and the option's in `translations/ui.jsonc` (en, de, fr). **No interface written**: the Jobs
   section of `/admin` draws every job from its options by itself.
10. **The status** is a new `suggesting.status()`: 10.5d's `pending_status()` unchanged, with `tried` (rows of
    `PGReconcileTried` whose stand-in is still a node below a head: the sweep's rule) and `suggested` (rows of
    `PGReconcileSuggested` whose node is still below a head and of a class of `hooks.unconfirmed`: the sweep's rule),
    both one join each by `PGIndexableNode(id)`. `status_json` gives it camelCase for `GET /api/reconcile/suggest`.
11. **The routes**: `POST /api/reconcile/suggest` with a body that may be absent (`{"classes": [...] | null,
    "again": false}`), `GET /api/reconcile/suggest`; both `CurrentAdmin` (401 not logged in, 403 not an admin, as
    the admin package's routes).
12. **The command `status`** prints a line each: waiting (claimed), the oldest mark (when any), waiting for the
    vectors, a rebuild in hand (only when there is), the worker's lease (none; a lease run out is said as none
    running, with whose and when), tried and left, suggestions not yet confirmed. Times in UTC, ISO 8601.
13. **The plans, read on Memgraph** (`EXPLAIN` on the empty test database, 2026-11-24): the page is `ScanAllByLabel
    (s :Unreconciled)` → filter → aggregate → order → limit; the heads `ScanAllByLabelProperties (h :HeadNode {id})`
    under the `UNWIND`. Neo4j (`:7693`, empty): `NodeByLabelScan s:Unreconciled` → filter → `EagerAggregation` →
    `Top head ASC LIMIT $page`; the heads `NodeIndexSeek h:HeadNode(id)` under the `Unwind`. A `Top` bounded by the page,
    over the aggregate of the stand-ins past the cursor: not the large-`SKIP` case of the notes, but not measured.
14. **Docs**: `implementation_docs/reconcile.md` (a section "What sets it off over what is stored", the opening and
    "Not built"), `guide/cli.md` (the rows of `worker`, `suggest`, `status`), `guide/vectors/reconcile.md` ("Turning
    it on", and the bullet "It does not act by itself", which was no longer true after 10.5d), `status.md`,
    `admin.md` (its table of tests), the skill's row. `implementation_docs/api.md` lists no app's routes: not
    changed.
15. **Not in `e2e/COVERAGE.md`**: no interface was written; the job appears in the Jobs section as any job does.
16. **`test_reconcile_learn_live.py` changed**: its admin-job test asserted the app has the one job
    `reconcile_learn`; it now lists both.
