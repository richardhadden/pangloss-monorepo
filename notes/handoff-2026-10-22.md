## Things worth knowing

- Python is 3.15 alpha: `coverage` does not load; a `sys.monitoring` tracer (`/tmp/pmk/linecov.py`, throwaway) was used for line
  coverage (79% -> 93% of `initialise_models/`).
- **Memgraph quirk:** testing a node's label with a long `a:X OR a:Y OR ...` chain made the server return the wrong path for a
  chain of 2+ nodes; the incoming query now tests `ANY(label IN labels(n) WHERE label IN $chain_labels)`.
- "Inline entities" do not exist: `create_inline` only lets a document's payload name an entity by UUID/URL for batch uploads
  (see `docs/models.md`, "Entity", and the memory `no-inline-entities`).
- Pydantic: fields put on a model by mutating `model_fields` are NOT inherited by a subclass made afterwards (cause of the
  edge-variant bug); `inherit_fields` is the workaround.
