# pangloss-core

What every Pangloss package shares: the settings classes (`BaseSettings`, `ClientSettings`, `DatabaseSettings`), logging, and
`pangloss_core.backend`, through which add-on packages reach whichever database is configured.

Reference: [implementation_docs/settings.md](../../implementation_docs/settings.md), [implementation_docs/logging.md](../../implementation_docs/logging.md).
