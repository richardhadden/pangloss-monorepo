# pangloss-interface

The web interface of Pangloss: a Solid 2.0 application (server-side rendered), the
library of components it is made from, and the commands and endpoints it needs. See
`docs/interface.md`.

Add `"pangloss_interface"` to `INSTALLED_APPS`: it adds `pangloss interface <command>`
and its endpoints under `/api/interface`.

Guide: [guide/interface](../../guide/interface/README.md).
