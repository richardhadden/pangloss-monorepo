# pangloss-learn

Fitting a weighted model from people's decisions: `fit` (a logistic regression, in numpy), `Model` (plain data, to
and from JSON), and `compare` (is the fitted model better than what was set by hand, on decisions it was not fitted
on). No database and nothing of Pangloss in it; `pangloss-reconcile` uses it.

See `implementation_docs/learn.md`.
