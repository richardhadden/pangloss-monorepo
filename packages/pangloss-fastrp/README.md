# pangloss-fastrp

The graph part of similarity for Pangloss: a vector for each document and entity from what it is joined to, by
FastRP over the joined graph. A part of `pangloss-vectors`. Built in Python, on both backends; the engine in a
Memgraph query module is not (deferred). See `implementation_docs/fastrp.md`, and `guide/vectors/` for how to use it.
