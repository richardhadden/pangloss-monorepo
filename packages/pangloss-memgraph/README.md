# pangloss-memgraph

The Memgraph database module: query builders, the functions the models call (`exposed_functions`), the migration backend,
users and review storage, setup, and `pangloss memgraph info | bulk-load | bulk-recover`. Set
`DATABASE_MODULE = "pangloss_memgraph.databases.memgraph"`. For Neo4j, see [`pangloss-neo4j`](../pangloss-neo4j).

Guide: [guide/backends](../../guide/backends/README.md). Reference: [docs/memgraph.md](../../docs/memgraph.md).
