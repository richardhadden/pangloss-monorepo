# pangloss-models

Declaring and initialising models: `Document`, `Entity`, `Embedded`, `Trait`, `EdgeModel`, `ReifiedRelation`, `SemanticSpace`,
`Conjunction`; the generated `Create`, `Update` and view models; `initialise()`; the export of the models, type stubs, the
migration planner, structured search and the meta slots. `pangloss_models.meta_kit` is the vendored `pydantic-meta-kit`.

Guide: [guide/getting-started](../../guide/getting-started/README.md). Reference: [implementation_docs/models.md](../../implementation_docs/models.md).
