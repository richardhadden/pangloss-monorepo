# pangloss-lsp

A language server for Pangloss models. Beside your type checker, it shows what `initialise()` refuses at the line
(on save, with quick fixes where the correction is obvious), completes the options of `Meta`, `RelationConfig` and
`FieldBinding` and the values they take, keeps the `.pyi` stubs up to date, and says on hover what a field means to
Pangloss.

Reference: [docs/language-server.md](../../docs/language-server.md).
